# User Data Collection & AI Career Suggestion

## Project Description

This project is a Python-based user data collection application that stores student information in a CSV file and uses Ollama AI to generate a personalized career suggestion.

## Features

- Collects student information through the terminal
- Stores the collected data in a CSV file
- Uses Ollama for AI-powered career suggestions
- Provides career recommendations based on technical skills and career goals
- Uses a local Llama 3.2 model through Ollama

## Technologies Used

- Python
- CSV
- Ollama
- Llama 3.2
- Git
- GitHub

## Information Collected

- Full Name
- Age
- College
- Department
- Email
- GitHub Profile
- LinkedIn Profile
- Technical Skills
- Career Goal

## How to Run

1. Install Python.
2. Install Ollama.
3. Download the `llama3.2:1b` model.
4. Open the project folder in VS Code.
5. Activate the virtual environment.
6. Run:

```bash
python app.py
